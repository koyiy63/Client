Tricks & techniques that actually help

Easy, repeatable tactics your learners can use on test day.

Listening

  • Before audio: underline keywords and predict the type of word (number, noun, adjective).
  • Watch for paraphrase: "purchase" = buy, "increase" = go up, "approximately" = about.
  • Spelling and numbers cost marks. Drill common sets (dates, addresses, prices) weekly.
  • If you miss one, skip fast. Do not lose the next answers.

Reading

  • Skim first: title, subheadings, first sentence of each paragraph.
  • True/False/Not Given: If not proven true or false by the text, it is Not Given.
  • Keywords rarely match exactly. Hunt synonyms and reformulations.
  • Move on from one hard question; return later with fresh eyes.

Writing Task 1

  • Write an overview with 2–3 big trends: highest/lowest, increases/decreases, comparisons.
  • Group data logically (e.g., 2000–2010 vs 2010–2020) instead of describing year by year.
  • Use range: approximately, just over/under, roughly, surged, dipped, plateaued.

Writing Task 2

  • Template: Intro (paraphrase + thesis), 2 body paragraphs (reason + example), brief conclusion.
  • Band 7+ cohesion: use reference words (this trend, such an approach, these challenges).
  • Clarity > complexity. Short sentences are okay if logical and precise.

Speaking

  • Part 1: Short but complete. Add one detail: "I prefer tea — especially jasmine — because…"
  • Part 2: 1‑minute plan; speak in small stories with linking: first, then, after that, finally.
  • Part 3: Opinion → reason → example → mini‑conclusion. Keep answers organized.
  • Pronunciation: practice word stress and chunking. Record and imitate 1 minute daily.

Easy templates

Task 2 intro

Many people believe that [topic]. In my view, [your position] because [reason 1] and [reason 2].

Part 3 answer

I think [opinion], mainly because [reason]. For example, [example]. So overall, [short wrap‑up].

Overview (Task 1)

Overall, [group A] shows the highest values while [group B] remains the lowest; moreover, [trend].

Common issues for Asian learners

  • Articles and plurals: drill minimal pairs (a student / students) and common collocations.
  • Prepositions: build a short list (interested in, depend on, responsible for) and recycle them.
  • Pronunciation: focus on /r/ vs /l/, long vs short vowels, and final consonants.
  • Intonation: practice rising tone for questions, falling for statements.
